====================================================================
 Worldstitch (ワールドステッチ) MOD 説明書  ―  Beta 0.5.2
====================================================================
 (English version: README_en.txt / 変更履歴: CHANGELOG.txt)
====================================================================

ネザーポータルのような「枠」を組んでゲートを作り、リンクさせることで
・同じセーブ内の離れた場所へワープ
・オーバーワールド/ネザー/エンドをまたいでワープ
・別のセーブデータそのものへワープ(高速ロード切り替え)
ができる、シングルプレイ専用MODです。

大事に育てた拠点はそのまま残しつつ、新しいワールドを探索したい
プレイヤー向けの機能です。


--------------------------------------------------------------------
1. 入手方法
--------------------------------------------------------------------
■ ゲートフレーム(gate_frame_block) … 1回で8個
    刻まれた深層岩(D)でエンダーパール(E)を3x3に囲む
        D D D
        D E D
        D D D

■ ゲートの目印帳(gate_linker)
    本(writable_book) + エンダーパール(シェイプレス)

※ ゲート内部の「ゲートポータル」はアイテムとして存在せず、枠を
   正しく組むと自動生成されます。

■ ボーナスチェスト
    ワールド新規作成時にONにすると、ゲートフレーム16個・目印帳1個が
    確定で追加されます(既存の中身には影響なし。ロットテーブルが
    他MOD等で丸ごと置き換えられている場合は追加されません)。


--------------------------------------------------------------------
2. ゲートの作り方
--------------------------------------------------------------------
ネザーポータルと同じ要領です。

  1. ゲートフレームで内側が空洞の長方形の枠を組む
     (内寸: 最小 幅2×高さ3 / 最大 21×21、四隅は無くてもよい)
  2. リンクを設定すると、内側に自動的にポータルが生成される(3章)
  3. ポータルに触れるとリンク先へワープ

ポータル面は、染料を持って右クリックすると色を変更できます
(リンク先の色も自動的に揃います)。

プレイヤーだけでなくMob・落下アイテム等も通行できますが、これは
同一セーブ内のリンク限定です。別セーブへのリンクはプレイヤー専用の
仕組みに依存するため、それ以外のエンティティは素通りします(7章)。


--------------------------------------------------------------------
3. リンクのやり方
--------------------------------------------------------------------
  【リンク元】
    1. 枠のどこか1ブロックを目印帳で右クリック
    2. 「この枠の目印をコピー」を押す(目印がクリップボードにコピーされる)

  【リンク先】
    3. リンクしたい枠を目印帳で右クリック
    4. 貼り付け欄に目印を貼り付ける(「貼り付け」ボタンでも可)
    5. 「リンクする」を押す

これで双方向にリンクされます(相手が別セーブの場合、次にそのセーブを
開いた時に自動で反対向きのリンクも設定されます)。枠のどのブロックを
操作しても同じゲートとして扱われます。


--------------------------------------------------------------------
4. 説明文・接続先の確認
--------------------------------------------------------------------
目印帳の画面で、このゲートの説明文(自由なメモ)を設定できます。
リンク済みのポータルにカーソルを合わせると、アクションバーに
「セーブ名 (x, y, z) 『説明文』」が自動表示されます。


--------------------------------------------------------------------
5. リンクの解除・破壊保護
--------------------------------------------------------------------
枠を壊さずにリンクだけ解除したい場合は、目印帳で「リンク解除」を
押します。枠自体を壊してもリンクは解除されます(装飾用の無関係な
枠ブロックを壊しても本体には影響しません)。

枠を誤って壊さないよう「破壊保護」も設定できます(目印帳の画面、
/worldstitch protect コマンド、コンフィグから)。保護中は岩盤と
同じ扱いで、殴っても一切反応しません。ポータル面自体も、破壊保護の
設定に関わらず常に破壊不可です(ネザーポータルと同じ仕様)。


--------------------------------------------------------------------
6. コマンド一覧
--------------------------------------------------------------------
目印帳が無くても、見ている枠に対して同じ操作ができます。

  /worldstitch mark                 目印を発行してチャットに表示
  /worldstitch link <目印>          指定した目印にリンク
  /worldstitch unlink                リンクを解除
  /worldstitch protect               破壊保護をON/OFF
  /worldstitch residency             離脱済みセーブ設定の現在値を表示
  /worldstitch residency allow       離脱済みセーブに直接アクセス可能にする
  /worldstitch residency block       自動案内に戻す(既定)
  /worldstitch residency clear       このセーブの離脱記録を消す


--------------------------------------------------------------------
7. 別セーブ・次元をまたぐワープについて
--------------------------------------------------------------------
別セーブへのワープは、現在のセーブを保存してから終了し、リンク先の
セーブを開き直す仕組みです(シングルプレイ限定)。移動元には
「離脱済み」の記録が残り、次に直接開こうとすると自動的に移動先へ
案内されます(6章のコマンドで調整可能)。

次元またぎは、オーバーワールド/ネザー/エンドどの組み合わせでも
リンクでき、同一セーブ内ならバニラのポータルと同様その場で切り替わります。

【注意】別セーブへのワープはキャラクターデータ(インベントリ・経験値・
エンダーチェスト等)をそのまま引き継ぐため、初回ワープ時にワープ先の
既存データは上書きされます。またリンクを解除してもデータは元に
戻らないため、両方のセーブに同じ持ち物が存在することになり、
アイテムの意図しない増殖につながる可能性があります。ワープ前に
ワープ先の持ち物を確認してください。


--------------------------------------------------------------------
8. コンフィグ(config/worldstitch.json)
--------------------------------------------------------------------
ModMenu導入時は設定画面からも変更できます(初回起動時に自動生成)。

  allowCrossDimensionTravel   (既定 true)  ネザー・エンドを絡めた移動の許可
  allowCrossSaveTravel        (既定 true)  別セーブへの移動の許可
  allowEnteringDepartedSave   (既定 false) 離脱済みセーブへの直接アクセス許可
  portalCooldownTicks         (既定 60)    ワープ直後の再ワープ猶予(20=1秒)
  minGateInnerWidth/Height    (既定 2/3)   ゲート内寸の最小サイズ
  maxGateInnerSize            (既定 21)    ゲート内寸の最大サイズ
  reverseLinkMaxRetryTicks    (既定 200)   戻りリンク再形成の再試行上限
  frameBreakProtectionEnabled (既定 true)  破壊保護機能そのものの有効/無効


--------------------------------------------------------------------
9. 注意事項
--------------------------------------------------------------------
  ・シングルプレイ専用です(別セーブ移動が統合サーバーに依存するため)
  ・別セーブへ移動する前は、念のためバックアップを取っておくことを推奨
  ・表示言語はMinecraft本体のLanguage設定に従います(日本語/英語の2言語)
